# 🍴 Fine Dine Restaurant

A modern, fully responsive restaurant landing page built with HTML and Tailwind CSS, featuring an elegant dining experience, menu highlights, reservation section, gallery, and newsletter subscription.

> Designed to showcase a premium restaurant with a clean UI, responsive layout, and engaging user experience.

---

# ✨ Features

- 🍽️ Elegant restaurant landing page
- 📱 Fully responsive design
- 🎨 Modern and clean UI
- 🏠 Full-screen hero section
- ⭐ Today's Special menu cards
- 📅 Online reservation section
- 🖼️ Food gallery
- 👨‍🍳 About restaurant section
- 📧 Newsletter subscription form
- 📍 Contact information & social links
- ⚡ Built with Tailwind CSS CDN
- 🌐 Smooth single-page navigation

# 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/syedasobiya-404/Fine-Dine-Restaurant.git
```

### Navigate to the project

```bash
cd Fine-Dine-Restaurant
```

### Open the project

Simply open the `index.html` file in your browser.

Or run with **Live Server** in Visual Studio Code.
